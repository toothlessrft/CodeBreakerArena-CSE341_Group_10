# CodeBreakerArena-CSE341_Group_10

**Feature 1:** Secret Code Selection & Difficulty [Arafat Hossain Ahad]
The program offers different difficulty levels with predefined variable-length and randomly generated codes. The selected code is stored in an array and the difficulty determines its length and game rules.
**Feature 2:** Guess Feedback Engine [Lamisa Hossain]
The program compares a player's variable-length guess with the secret code and identifies how many digits are correct and in the correct position and how many are correct but in the wrong position.
**Feature 3:** Guess History & Undo [Anandita Sahin]
The program stores previous guesses and their feedback. Players can view their history and undo their most recent guess using a stack.
**Feature 4:** Two-Player Turn Management [Arafat Hossain Ahad]
The program alternates turns between Player 1 and Player 2, tracks each player's attempts, and prevents actions when it is not their turn.
**Feature 5:** Duplicate Guess Detection [Lamisa Hossain]
The program checks the player's previous guesses and identifies if they submit a guess that has already been attempted.
**Feature 6:** Scoring & Winner Determination [Anandita Sahin]
The program calculates each player's score based on attempts and correct-position matches, then determines and displays the winner when the secret code is solved or the game ends.
